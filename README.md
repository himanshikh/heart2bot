# Heart2Bot Project

**Emotional Support Chatbot with Persona Memory and Interpretable Strategies**  


## Overview

**Heart2Bot** is a hybrid emotional support chatbot that combines:
- **Persona-aware memory** for personalization  
- **Emotion recognition** for empathy  
- **Strategy interpretability** for transparency  
- **LLM distillation** for efficiency

It generates emotionally intelligent, interpretable, and cost-effective responses to support mental wellness conversations.

---

## Key Features

- **Persona Memory:** Long-term and short-term user profiling with user-controlled updates.  
- **Emotion + Strategy Reasoning:** Real-time emotion detection and support strategy mapping (reflection, suggestion, reassurance).  
- **Efficient Generation:** LLM-based self-chat data distillation into a compact student model.  
- **Interpretable Outputs:** Each response tagged with its emotional support strategy.  

---

## Methodology

User Input
→ Persona Memory
→ Emotion Detection
→ Strategy Selection
→ Student Model Response
→ Final Output

---

## Datasets

- **ESConv (ACL 2021):** Emotional support dialogues with strategy labels.  
- **EmpatheticDialogues (ACL 2019):** Emotion-grounded dialogues (32 emotions).  
- **Synthetic Self-Chats:** Generated via GPT-4 for fine-tuning and efficiency.
